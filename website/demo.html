A session in progress, the way it looks in your terminal. Type, or take one of the suggestions — they change as the session moves through a day, a week, a review cycle.

This session is recorded. A live agent needs a model at runtime and this site has no backend, so the replies were captured by running Valor's own command specs against the seeded demo profile in the repo — fictional engineer, fictional tickets, invented colleagues. Type something it hasn't heard and it will say so rather than improvise. The review console below is not recorded: that one is the real artifact, and you can drive it.
