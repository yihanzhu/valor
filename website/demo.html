About this demo

The session is recorded. A live agent needs a model at runtime and this site has no backend, so the replies were captured by running Valor against a seeded profile — a fictional engineer at L3 targeting L4, fictional tickets, every integration switched off, real output. Ask something it hasn't heard and it says so.

The review console is not recorded. That's the real artifact.

Run the whole thing yourself, against a throwaway home:

HOME=~/valor-demo bash install.sh && python3 examples/demo/seed.py ~/valor-demo
